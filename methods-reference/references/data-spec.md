# 数据准备与清洗规范表

| 项目 | 具体内容 |
|---|---|
| **适用场景** | 任何模型估计之前；多表合并、缺失值、异常值、变量构造、指数构建、面板唯一性核对 |
| **必问信息** | ①有几张表、各表分析单位是什么？②有无官方 Codebook/数据字典？③目标分析样本如何定义？④面板 ID-时间组合是否唯一？⑤每步筛选前后 N 是多少？ |
| **常见误解** | ①"缺失值直接删掉就行"——先判 MCAR/MAR/MNAR，MNAR 下删样本有偏；②"异常值都该删掉"——先区分录入错误与真实极端值；③"缩尾后不用报告"——须报告阈值并做不缩尾对照；④"merge 没报错就是成功"——必须查 _merge 三类计数；⑤"在原始数据上改最快"——原始数据必须只读，清洗全程脚本化 |
| **误判防护** | 通用规则见 `../../_shared/misconception-guards.md`；"不一定删/还要看缺失机制"等讨论语气不判为误解；涉及"删掉样本让结果好看"时按学术诚信红线处理 |
| **结果解释规范** | 清洗日志逐行报告：操作、原因、N 变化；缩尾报告分位阈值（如 1%/99%）；合并报告 _merge=1/2/3 各多少及未匹配原因；指数构建报告维度与合成公式 |
| **何时不适用（替代）** | 缺失比例高且依未观测因素 → 多重插补（mi impute）并做机制讨论，而非直接删除；异常值是真实分布特征 → 保留+稳健回归（如 rreg）或对数变换，而非一律缩尾 |
| **必报结果清单** | 原始→分析样本的观测数变化表、缺失率统计、异常值处理记录、merge 核对结果、变量字典（含构造口径）、从只读原始数据出发的可复现主 do-file |
