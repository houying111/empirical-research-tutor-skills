# OLS多元回归规范表

| 项目 | 具体内容 |
|---|---|
| **适用条件** | 因变量连续且近似正态；X与误差项不相关（外生性）；无完全多重共线性；误差项同方差（或使用稳健标准误） |
| **必问信息** | ①因变量Y是什么？连续变量吗？②核心自变量X是什么？预期影响方向？③控制了哪些变量？为什么选这些控制变量？④样本量多大？是否有极端值？ |
| **常见误解** | ①“R方高就说明模型好”——R方高不代表因果效应可信；②“显著就是因果”——显著只说明条件相关，不代表因果；③“控制变量越多越好”——过度控制可能引入偏误；④“不显著就换变量”——应先分析原因（方向、标准误、函数形式） |
| **结果解释规范** | “在其他条件不变的情况下，X每增加1个单位，Y平均变化[系数]个单位，这个效应在[显著性水平]上[显著/不显著]。”；需报告稳健标准误；需区分统计显著与经济显著 |
| **核心假设** | ①随机抽样（iid）②无极端异常值③E(u_i\|X_i)=0（条件均值独立）④无完全多重共线性 |
| **误判防护** | 误解判定只在完整句子内匹配（按 。！？和换行切分），不跨句拼凑关键词；句中有"不一定/并不能/并非/错误/不对/有待/仍需"等否定或存疑词时不判为误解，先追问确认；"95% 置信区间"不是百分比主张，仅"提高了20%"这类主张形式触发 |
| **何时不适用（替代）** | 需要因果效应且有政策冲击 → DID/合成控制/RDD；Y 为 0/1 → Logit/Probit；Y 为计数 → Poisson；无法靠控制变量解决的内生性 → 工具变量 |
| **必报结果清单** | 系数+稳健标准误（括号内）、显著性星号、样本量 N、R²、F 统计量；正文含描述性统计表；如聚类需注明聚类层级 |
| **遗漏变量偏误（OVB）** | 当遗漏变量同时影响Y且与X相关时，OLS估计有偏。偏误方向 = 遗漏变量对Y的效应 × 遗漏变量与X的相关系数符号 |
