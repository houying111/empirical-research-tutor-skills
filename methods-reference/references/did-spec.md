# 同批DID（经典2×2）规范表

| 项目 | 具体内容 |
|---|---|
| **适用条件** | 处理组和对照组在政策前具有平行趋势；政策在同一时间点对所有处理组生效（同批处理）；有明确的前后期划分 |
| **必问信息** | ①处理组和对照组如何定义？②政策是否在同一时间对所有处理组生效？（如果是分批生效，属于交错DID）③政策前有几期数据可用于平行趋势检验？④聚类层级是什么（省份/城市/个体）？ |
| **常见误解** | ①“跑完回归就算DID”——平行趋势检验是核心前提，不可跳过；②“事件研究法系数不显著就是平行趋势成立”——将安慰剂检验与显著性检验混淆是常见错误；③“TWFE对交错DID也适用”——交错DID中TWFE可能产生负权重问题，导致估计偏误；④“标准误聚类到个体层面就行”——应聚类到处理发生的层级（如省份），聚类层级过低会高估显著性 |
| **结果解释规范** | “政策使处理组的Y平均变化了[系数]个单位，这一效应在[显著性水平]上显著。”；需报告事件研究图，展示政策前系数不显著；需说明标准误聚类层级 |
| **平行趋势检验** | 事件研究法（Event Study）：以政策前一期为基准，绘制各期动态效应图，观察政策前各期系数是否显著异于零 |
| **安慰剂检验** | 随机分配处理组，重复多次（如500次），观察真实系数是否落在安慰剂分布之外；或把政策时间人为前移做伪时间点检验 |
| **误判防护** | 误解判定只在完整句子内匹配（按 。！？和换行切分），不跨句拼凑关键词；句中有"不一定/并不能/尚未通过/错误/不对/有待/仍需/放弃"等否定或存疑词时不判为误解，先追问确认；误解关键词须用4字以上组合词且仅匹配主张性表述（如"可以直接报告"）；"等于/相当于"后仅允许标点或空格再接方法名；"95% 置信区间"不是百分比主张 |
| **何时不适用（替代）** | 无对照组（政策覆盖所有单元）→ 合成控制/中断时间序列；处理由连续变量过门槛决定 → RDD；只有横截面数据 → 无法做真DID，用OLS并如实报告局限 |
| **必报结果清单** | 基准系数+聚类标准误（注明层级）、事件研究图（政策前系数不显著）、安慰剂检验结果、平行趋势讨论、样本期与处理组定义说明 |

## 交错 DID 补充

政策分批实施、处理效应异质时，TWFE 是所有 2×2 比较的加权平均，权重可为负（Goodman-Bacon 分解，"已处理组"被当对照的禁止比较）。推荐估计量：Callaway & Sant'Anna（`csdid`）、Sun & Abraham（`eventstudyinteract`）、de Chaisemartin & D'Haultfœuille（`did_multiplegt`）。配套案例：实证学徒 case_003《智慧城市试点》。
