# 合成控制（Synthetic Control）规范表

| 项目 | 具体内容 |
|---|---|
| **适用条件** | 处理单元数量少（经典方法最适合 1 个）；政策前有较长时间序列（最好 10 期以上）；缺乏可比对照组或对照组很少；donor pool 干净（不含受政策或溢出影响的单元） |
| **必问信息** | ①受政策影响的单元有几个？②政策前有多少期数据？③donor pool 包含哪些单元？其中是否有受同一政策/溢出影响的？④用什么预测变量拟合政策前轨迹（政策前多期结果值最重要）？ |
| **常见误解** | ①"合成控制也能用于很多处理单元"——经典 SCM 针对单个处理单元，多单元需广义 SCM/矩阵补全类扩展；②"政策前拟合好，结论就可信"——存在过拟合风险，推断必须靠安慰剂；③"donor pool 放相似单元就行"——受政策或溢出影响的单元必须剔除，否则污染合成控制；④"政策后 gap 大就等于显著"——推断靠安慰剂排名与 RMSPE 比值，不靠 t 值 |
| **误判防护** | 误解判定只在完整句子内匹配（按 。！？和换行切分），不跨句拼凑关键词；句中有"不一定/并不能/并非/错误/不对/有待/仍需"等否定或存疑词时不判为误解，先追问确认；学生回复是反问或"我并没有说……"时先致歉澄清 |
| **结果解释规范** | "政策实施后，处理单元与合成控制的差距（gap）平均为 [gap]/期；in-space placebo 显示真实单元的 gap 在 [排名/百分比] 的安慰剂分布之外，post/pre RMSPE 比值为 [值]。"禁止只报 gap 不报安慰剂排名 |
| **何时不适用（替代）** | 处理单元多且对照组丰富 → DID；政策前期太短 → 无法拟合可信合成控制，如实报告局限或改用中断时间序列；结果变量政策前波动过大且找不到拟合 → 讨论方法边界 |
| **必报结果清单** | donor pool 权重表、政策前拟合图（处理组 vs 合成控制）、gap 序列图、in-space placebo 的 gap 分布、post/pre RMSPE 比值排名；Stata 用 `synth`（R 用 Synth/augsynth/gsynth） |

配套案例：实证学徒 case_004《房产税试点》（合成控制）；case_002《全面二孩》为无对照组反例，用于"为什么不能 DID"的过渡讨论。
