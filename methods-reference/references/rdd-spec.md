# 断点回归（RDD）规范表

| 项目 | 具体内容 |
|---|---|
| **适用条件** | 处理由连续驱动变量与门槛值决定（sharp：完全由过线决定；fuzzy：过线只提高受处理概率）；门槛附近个体近似随机分布；驱动变量不能被精确操纵 |
| **必问信息** | ①驱动变量是什么？门槛值多少？②sharp 还是 fuzzy？③个体能否精确操纵驱动变量取值（复读刷分、申报材料可控）？④驱动变量是连续还是取值稀少的离散变量？ |
| **常见误解** | ①"DID 里控制了驱动变量就等于 RDD"——错误。DID 用两组前后变化之差识别，RDD 用门槛处跳变识别，是两套不同的识别策略，加控制变量不会互相转化；②"RDD 估计适用于全样本"——它只是门槛附近的局部平均处理效应（RLATE）；③"多项式阶数越高越可信"——高阶全局拟合存在边界振荡，推荐低阶多项式+带宽内估计；④"分箱可用任意等宽分箱"——应用最优分箱（如 esmv） |
| **误判防护** | 误解①的触发规则：组合词"控制了/驱动变量/等于RDD/相当于RDD"，且"等于/相当于"之后仅允许标点或空格直接接"RDD"；句中出现"并不是/不等于/不能/不对/并非"等否定词时不判为误解，先追问确认；其余误解按完整句子内匹配（。！？换行切分）、否定语境豁免处理 |
| **结果解释规范** | "在门槛 [c] 附近，驱动变量越过门槛使 Y 平均跳变 [系数]，该效应在 [显著性水平] 上显著（带宽 [h]，三角核，稳健偏差修正置信区间）。"结论必须表述为门槛附近的局部效应（RLATE），禁止外推为全样本效应 |
| **何时不适用（替代）** | 驱动变量取值稀少（离散）→ 操纵检验不可靠，RDD 勉强成立需如实报告局限；门槛处存在明显操纵 → 识别失效，考虑其他设计；无门槛但有时点政策 → DID/合成控制 |
| **必报结果清单** | RD 图（最优分箱）、McCrary 密度操纵检验、协变量平衡检验、多带宽与多阶数敏感性分析、结论以 RLATE 表述；Stata 用 `rdrobust`/`rddensity`/`rdplot` |

配套案例：实证学徒 case_005《国家扶贫开发工作重点县认定》（RDD）。
