# 面板固定效应（FE）规范表

| 项目 | 具体内容 |
|---|---|
| **适用条件** | 面板数据（同一批个体被追踪多期）；存在不随时间变化的不可观测个体异质性，且该异质性与X相关 |
| **必问信息** | ①数据是面板还是重复截面？②个体ID和时间变量是什么？③需要控制个体固定效应还是时间固定效应还是双向固定效应？④时间维度T有多大？ |
| **常见误解** | ①“固定效应控制了所有遗漏变量”——错误。固定效应只能控制不随时间变化的遗漏变量；②“固定效应是万能药”——在动态面板中会出现Nickell偏误；③“固定效应总是比混合OLS好”——当不可观测异质性与X不相关时，FE反而损失效率；④“可以把非时变协变量直接放进FE模型”——非时变变量会被固定效应吸收，无法估计其系数 |
| **结果解释规范** | “控制个体固定效应后，X每变化1个单位，Y平均变化[系数]个单位。”；需注意FE仅利用组内变异，解释的是“个体自身随时间变化”的效应 |
| **与随机效应的选择** | 当不能把观测个体视为从大总体中随机抽样时，使用固定效应；否则可使用随机效应 |
| **标准误** | 聚类标准误（聚类到个体层面），以处理序列相关和异方差 |
| **误判防护** | 误解判定只在完整句子内匹配（按 。！？和换行切分），不跨句拼凑关键词；句中有"不一定/并不能/并非/错误/不对/有待/仍需"等否定或存疑词时不判为误解，先追问确认；学生回复是反问或"我并没有说……"时先致歉澄清 |
| **何时不适用（替代）** | 核心变量在个体内不随时间变化 → 无法用个体FE（改用Mundlak/组间效应，或放弃FE）；短面板动态模型（含滞后被解释变量）→ 差分/系统GMM；存在政策冲击 → 直接转入DID |
| **必报结果清单** | 系数+聚类稳健标准误（注明层级）、样本量N与个体数、within R²、个体/时间FE是否同时控制、（若讨论RE）Hausman检验结果 |
