# 工具变量（IV/2SLS）规范表

| 项目 | 具体内容 |
|---|---|
| **适用条件** | 核心解释变量 X 存在内生性（遗漏变量、反向因果、测量误差），且能找到工具变量 Z；Z 满足相关性（与 X 显著相关）与外生性/排他性（只通过 X 影响 Y） |
| **必问信息** | ①X 的内生性来自哪一类？②候选 Z 是什么，制度背景为何"近乎随机"？③Z 影响 Y 是否存在不经过 X 的路径（排他性反例）？④识别类型：恰好识别还是过度识别？ |
| **常见误解** | ①"外生性可以用统计检验证明"——恰好识别时无法检验，只能制度论证；过度识别检验不拒绝≠外生；②"第一阶段系数显著就是强工具"——须看第一阶段 F≥10（经验标准）；③"2SLS 系数是全样本平均效应"——异质性效应下是依从者（compliers）的 LATE；④"工具越多越好"——冗余弱工具加剧有限样本偏误 |
| **误判防护** | 通用规则见 `../../_shared/misconception-guards.md`（句内匹配、否定豁免、质问处理）；"不能证明外生/不一定外生"等讨论语气不判为误解，先追问 |
| **结果解释规范** | "在依从者子样本中，X 每变化 1 个单位，Y 平均变化 [系数]（2SLS，[稳健/聚类]标准误）；第一阶段 F=[值]。"必须同时给出工具变量外生性的制度论证；弱工具下用 LIML 对照 |
| **何时不适用（替代）** | 找不到排他性可信的 Z → 不勉强做 IV，改用面板 FE/DID/RDD 等设计；内生性来自测量误差且有重复测量 → 可用重复测量作工具；X 不存在内生性 → 直接 OLS 更有效 |
| **必报结果清单** | 第一阶段方程与 F 统计量（Cragg-Donald/Kleibergen-Paap）、2SLS 系数与稳健/聚类标准误、识别不足与弱工具检验、过度识别检验（若适用）、外生性的制度论证、LATE 适用人群讨论；Stata 用 `ivreg2`/`ivreghdfe` |
