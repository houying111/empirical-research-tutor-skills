# 掌握度 Rubric（各技能学完应能独立完成的事）

> 用法：学生完成某技能陪练后，用本清单做行为式自评/他评。
> 判定标准只有两档：**能独立完成**（不需提示即可说出/做出）与**仍需提示**。
> 清单同时是答辩时"教学效果可观测"的证据——每条都是可当场演示的行为。

## ols-tutor

- [ ] 能说出 OLS 系数的标准解读句式，并主动加上"在其他条件不变的情况下"
- [ ] 能区分混淆变量、中介变量、碰撞变量，说明为什么后两类不应控制
- [ ] 看到 0/1 因变量能指出这是 LPM，系数按百分点解读、须稳健标准误
- [ ] 能解释异方差的影响（系数不偏、标准误被低估）并给出修正命令
- [ ] 能主动说明 OLS 结果只是条件相关，指出反向因果与遗漏变量两条威胁

## fe-tutor

- [ ] 能用"和过去的自己比"解释组内识别，说出 FE 能/不能控制的三类变量
- [ ] 能诊断"系数被吸收"（非时变变量）与"样本量缩水"（单期个体被删）
- [ ] 能用 xtsum 分解 between/within 变异，解释组内变异不足的后果
- [ ] 能说出 FE 与 RE 的假设差异，以及社科场景默认 FE 的理由
- [ ] 能解释 FE 与 DID 的关系（TWFE 是 DID 的主力模型，但识别信息不同）

## did-tutor

- [ ] 能口述 DID 直觉（变化之差）与平行趋势假设
- [ ] 能独立设定事件研究法（基准期取政策前一期）并读图判断
- [ ] 能设计安慰剂检验（随机处理组 × 多次）并说明判读方式
- [ ] 能解释交错 DID 下 TWFE 的负权重问题，说出至少一个替代估计量
- [ ] 能正确选择聚类层级（政策分配发生的层级）

## synctrl-tutor

- [ ] 能判断什么场景必须放弃 DID 改用合成控制（无对照组/单一处理单元）
- [ ] 能解释权重与 donor pool 的作用，说明污染 donor pool 的后果
- [ ] 能说明为什么政策前拟合图是"质量合格证"
- [ ] 能解释推断为何不靠 t 值，而靠 in-space placebo 排名与 RMSPE 比值
- [ ] 能列出合成控制必报的四样结果

## rdd-tutor

- [ ] 能用门槛附近局部随机化解释 RDD 的识别逻辑
- [ ] 能区分 sharp 与 fuzzy RDD，说出 fuzzy 的 IV 解读
- [ ] 能说明操纵检验与协变量平衡检验为何是前置条件
- [ ] 能把结论表述为 RLATE，并拒绝外推到全样本
- [ ] 能解释"DID 控制驱动变量 ≠ RDD"（识别信息来源不同）

## iv-tutor

- [ ] 能说出工具变量的两个条件（相关性、外生性）及各自的检验方式
- [ ] 能解释弱工具变量的后果（偏误放大）与第一阶段 F>10 的经验标准
- [ ] 能说明过度识别检验的适用前提与局限（不能证明外生性）
- [ ] 能把 2SLS 系数正确表述为依从者（compliers）的 LATE
- [ ] 能对一个候选工具变量同时提出"支持外生"和"威胁外生"的论证

## data-tutor

- [ ] 能在跑模型前完成数据体检（缺失率、分布、极端值、ID-时间唯一性）
- [ ] 能区分 MCAR/MAR/MNAR 并说明各自对处理方式的影响
- [ ] 能规范执行缩尾/截尾并说明理由与阈值选择
- [ ] 能写出从原始数据到分析样本的可复现 do-file（不手改原始数据）
- [ ] 能在合并前后做观测数与关键变量的一致性核对

## research-tutor（综合能力）

- [ ] 能把一个选题操作化为"Y / X / 分析单位 / 数据类型"
- [ ] 能根据数据结构与识别条件在六类方法间做有理据的选择
- [ ] 能在平行趋势失败、无对照组、存在门槛等情形下说出替代路线
- [ ] 能列出一份分析的必报结果清单与数据合规要点
