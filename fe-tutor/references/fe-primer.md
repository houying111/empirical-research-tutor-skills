# 面板固定效应入门导读（本科生友好版）

## 核心直觉

固定效应 = 只用"每个个体自身随时间的变化"来识别效应。
个体之间的差异（地区文化、企业禀赋、个人能力等）全部被个体固定效应吸收——
因此 FE 天然排除了"不随时间变化的遗漏变量"造成的污染。

## 能控制什么、不能控制什么

| 变量类型 | 举例 | 固定效应能否控制 |
|---|---|---|
| 不随时间变化的个体特征 | 性别、民族、出生地 | 能（被个体 FE 吸收） |
| 同期对所有个体相同的冲击 | 金融危机、全国性政策 | 能（时间 FE 吸收） |
| 随时间变化的遗漏变量 | 个体能力变化、企业策略调整 | 不能 |
| 组内不变、组间变化的变量 | 省级政策在省内各年不变 | 能（加入省份 FE 后） |

## FE 还是 RE？

- **RE 假设**：个体效应与 X 不相关；**FE** 允许任意相关
- 现实中"能力"与"教育"、"企业规模"与"研发投入"大多相关，社科场景 RE 假设很难成立，**默认 FE**
- Hausman 检验只作辅助；理论判断优先——先问"遗漏的个体特征与核心解释变量相关吗？"

## 常见坑

1. **非时变变量估不出系数**：个体 FE 模型里放 `i.gender` 会因共线被 drop。要估计时不变变量：去掉个体 FE、改用 Mundlak（相关随机效应）或组间效应模型
2. **组内变异不足**：核心 X 在个体内几乎不随时间变 → FE 识别力弱、标准误大。先用 `xtsum` 分解 between/within 变异
3. **动态面板 Nickell 偏误**：模型含被解释变量滞后项且 T 较小时，FE 估计有偏。改用差分/系统 GMM 或偏误修正估计
4. **标准误**：聚类到个体层面，同时处理序列相关与异方差；存在跨个体溢出时考虑双向聚类
5. **单期样本被删**：只出现一期的观测在 FE 下自动被丢，样本量会缩水——报告时核对 N 的变化

## 常用 Stata 命令

```stata
xtset id year
xtsum x                              // 分解 between / within 变异
xtreg y x, fe cluster(id)            // 基准 FE
reghdfe y x, absorb(id year) cluster(id)   // 双向固定效应（高维 FE）
hausman fe_model re_model            // FE vs RE 辅助判断
```

## 与 DID 的关系

双向固定效应（个体 FE + 时间 FE）就是 DID 的主力估计模型。
交错 DID 的问题出在处理变量设定与异质性处理效应权重上（见 did-tutor 技能），
不是 FE 本身的问题——学生把两者混为一谈时要拆开讲清。
